# Descoberta web — desativada

O Radar de Leilões usa exclusivamente os eventos cadastrados no Google My Maps.

O código e os arquivos antigos de descoberta permanecem no repositório apenas como
histórico técnico. Eles não são chamados pelo workflow, pelo pipeline, pelo indexador
ou pelo gerador da página. O workflow de descoberta profunda foi removido para impedir
qualquer execução agendada ou manual fora do mapa.

Os sites dos leiloeiros e os editais continuam sendo consultados somente para obter os
lotes vinculados a um evento que já existe no mapa.
